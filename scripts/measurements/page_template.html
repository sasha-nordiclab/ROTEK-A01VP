Heights

Stand the pump on a flat table with the mounting face down. Measure every height from the table with the depth rod. The ribs rest on the table, so the pockets don't matter.

Lengths

Lengths along the pump run from the tip of the inlet barb, the part straight on the axis.

Priority

A rows shape the holder: mounting plate, slots, outer size, outlet and cable. Do them first. B rows refine the shape.

Δ colours

Δ is your value minus the model. Green is within tolerance, amber is up to 3× tolerance, red is more. Rows marked check disagree with the drawing or with an earlier reading.
